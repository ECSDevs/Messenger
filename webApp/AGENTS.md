# webApp — Compose Multiplatform / Kotlin/Wasm browser shell

A third target of the same KMP app — not a second UI: the browser runs the identical screens, repositories, and design system.

- **Targets**: `shared` declares `wasmJs { browser() }`; the entry point is `webApp/src/wasmJsMain/kotlin/cc/ptoe/messenger/web/Main.kt` (installs the bridge, builds `AppContainer`, calls `ComposeViewport(document.body)`). `:webApp` owns `binaries.executable()` — `:shared` is a library and must not.
- **Rust core over wasm-bindgen**: `messenger-wasm` mirrors `messenger-ffi`'s surface method-for-method (see `core/rust/AGENTS.md` — new methods go to both boundaries). `buildRustWasm` + `generateWasmBindings` compile `messenger-wasm` to wasm32 and run `wasm-bindgen --target web` into `webApp/build/wasm/`, registered as a `wasmJsMain` resource root; the Kotlin bridge imports the glue via the bare specifier `messenger-wasm-bindings`, aliased to that path in the committed `webpack.config.d/02-wasm-bindings.js` (a relative specifier resolves against the compiled Kotlin module's own directory). Toolchain prereqs are non-Gradle: `rustup target add wasm32-unknown-unknown` + `cargo install wasm-bindgen-cli` (version pinned in `Cargo.lock`).
- **Cloud facade split**: the UI depends on `domain/repository/CloudFacade`. Android/Desktop use `CloudSyncRepository` (`jvmSharedMain`); web uses `RustCloudFacade` (delegates to `CoreBridge`; keeps only the 750 ms sync debounce, the `syncError` channel, login/logout cleanup, and the cookie-aware Ktor client Coil uses). Selection is per-target in `createLocalStores` (`di/LocalStores.kt`).
- **Same-origin hosting**: the bundle is served from `server/public/app/` at `/app`, so `/api/*` and `/v1/*` share the page origin and the `messenger_session` cookie works with no CORS and no server API change. `server/next.config.ts` sends `Cross-Origin-Opener-Policy: same-origin` + `Cross-Origin-Embedder-Policy: require-corp` for `/app/:path*` ONLY (COEP breaks third-party embeds site-wide) and rewrites `/app` → `/app/index.html`; the dev server gets the same headers from `webpack.config.d/01-devserver.js`. `RustCloudFacade` pins the sync engine's server URL to `window.location.origin` at construction.
- **The bundle is never committed** (~28 MB build product). `ci.yml`'s `publish-web-client` job republishes it to the rolling `web-client` GitHub Release; `server/scripts/fetch-web-client.mjs` (wired as `pnpm web:client` in the server build) downloads that exact tag (NOT `/releases/latest`) into `public/app/` and injects `<base href="/app/">`. Download failure warns and continues (`WEB_CLIENT_REQUIRED=1` makes it fatal). `server/eslint.config.mjs` ignores `public/app/**`. `:webApp:copyWebAppDistribution` is the LOCAL fast loop (syncs straight into `server/public/app/`) and is not part of deploy.
- **CJK/text rendering**: CMP before 1.12.0 has no font fallback on wasm (Latin-only default ⇒ CJK tofu). The project tracks **CMP 1.12.x** for on-demand Noto subset download + recompose — do not downgrade `composeMultiplatform`/`jbComposeMaterial3` below 1.12. Fallback needs network access to `fonts.gstatic.com`; tofu can briefly flash on first paint.
- **`:shared` disables `checkComposeUiTestConfigurationForWasmJs`** (CMP 1.12 would demand `binaries.executable()` on the library's wasmJs target; the wasm tests live in `jvmSharedTest`, and only `:webApp` may declare an executable).
- **Toolchain notes**: `gradle.properties` disables Node download (`kotlin.js.nodejs.download=false`, `kotlin.js.yarn=false`); `settings.gradle.kts` declares the ivy repos for the pinned Node/Binaryen distributions and uses `RepositoriesMode.PREFER_SETTINGS`; npm/yarn lockfiles live in git-ignored `kotlin-js-store/` (`./gradlew kotlinWasmUpgradePackageLock` refreshes them).
- **Deliberate degradations** (browser sandbox, not unfinished): no terminal/workspace tools (empty `createBuiltinChatTools()` ⇒ no `tools` array), no stdio MCP (remote SSE/HTTP MCP works), no companion runtime (`runtimeTerminalSupported = false`), no models.dev metadata, images ride as `data:` URIs, and Coil must never receive an `okio.Path` on web (its js/wasm `defaultFileSystem()` throws).

## Commands

```bash
./gradlew --no-daemon :webApp:wasmJsBrowserDevelopmentRun   # dev server (COOP/COEP on)
./gradlew --no-daemon :webApp:wasmJsBrowserDistribution     # production bundle
./gradlew --no-daemon :webApp:copyWebAppDistribution        # local: sync into server/public/app/
cd core/rust && cargo check --target wasm32-unknown-unknown -p messenger-wasm
```
