# AI Chatbot App - Verification Checklist

## 项目架构与基础
- [ ] 项目使用 Kotlin + Jetpack Compose 开发，代码结构清晰
- [ ] 采用 MVVM 分层架构（data/domain/presentation）
- [ ] 项目可成功编译，无编译错误
- [ ] 所有依赖正确引入，无版本冲突

## 数据库层
- [ ] Provider、Model、Agent、Conversation、Message 实体类定义正确
- [ ] 各 DAO 接口实现了完整的增删改查
- [ ] 表关系正确：Provider 1:N Model, Agent 1:N Conversation, Conversation 1:N Message
- [ ] 应用重启后数据持久化保留，无丢失
- [ ] Room 数据库配置正确，迁移策略完善

## 网络层
- [ ] Retrofit + OkHttp 正确配置
- [ ] `/v1/models` 接口可正确调用并解析返回的模型列表
- [ ] `/v1/chat/completions` 流式接口支持 SSE
- [ ] API Key 通过 Authorization Header 正确传递
- [ ] 网络请求有超时设置和错误处理
- [ ] SSE 流式解析器正确处理数据块

## Provider 管理
- [ ] Provider 列表页面展示所有已配置的 Provider
- [ ] 可添加 Provider（名称、Base URL、API Key）
- [ ] 可编辑和删除已有的 Provider
- [ ] API Key 加密存储，明文不暴露在日志或界面中
- [ ] 表单验证：必填项、URL 格式校验
- [ ] 删除 Provider 时有确认对话框

## 模型管理
- [ ] 每个 Provider 下可管理多个模型
- [ ] 可手动添加模型（模型 ID + 显示名称）
- [ ] 可通过 `/v1/models` 接口同步获取模型列表
- [ ] 同步的模型可选择性保存
- [ ] 模型可启用/禁用
- [ ] 同步过程显示加载状态，失败时有错误提示

## Agent 管理
- [ ] Agent 列表页面展示所有 Agent
- [ ] 首次启动自动创建"标准 Agent"
- [ ] 可创建、编辑、删除 Agent
- [ ] Agent 可配置：名称、系统提示词、默认模型、温度、Top P、max tokens
- [ ] 模型选择器只显示已启用的模型
- [ ] 删除 Agent 时有确认对话框

## 对话管理
- [ ] 对话列表按时间倒序排列
- [ ] 每个对话项显示最近消息预览和时间
- [ ] 对话按 Agent 归类，切换 Agent 后对话列表正确过滤
- [ ] 可创建新对话
- [ ] 可重命名对话
- [ ] 可删除对话，有确认提示

## 聊天界面 (Telegram 风格)
- [ ] 用户消息气泡在右侧，蓝色背景，圆角
- [ ] AI 消息气泡在左侧，浅色/灰色背景，圆角
- [ ] 顶部栏显示对话标题，有返回按钮
- [ ] 底部输入框支持多行输入，有发送按钮
- [ ] 消息列表自动滚动到最新消息
- [ ] 消息气泡显示发送时间
- [ ] 整体视觉风格类似 Telegram

## 聊天功能
- [ ] 可发送文本消息
- [ ] AI 回复以流式方式逐块显示（打字机效果）
- [ ] 消息状态正确：发送中（loading）、已发送、错误
- [ ] 发送失败时有错误提示和重试选项
- [ ] 可复制消息内容
- [ ] 可重新生成 AI 回复
- [ ] 可中断正在生成的回复
- [ ] 中断后保留已生成的内容

## 导航与主题
- [ ] 底部导航栏有三个入口：对话、Agent、设置
- [ ] 底部导航切换流畅，页面状态正确
- [ ] 支持深色/浅色主题切换
- [ ] 支持跟随系统主题
- [ ] Material You 动态配色生效（Android 12+）
- [ ] 深色模式下文字清晰可读

## 设置页面
- [ ] 设置页面布局清晰，分类合理
- [ ] 主题切换功能正常，即时生效
- [ ] Provider 管理入口可从设置页进入
- [ ] 显示应用版本等关于信息
- [ ] 有清除数据的选项（带确认）

## 端到端流程
- [ ] 完整流程：添加 Provider → 同步模型 → 创建 Agent → 发起对话 → 发送消息 → 接收流式回复
- [ ] 退出应用后重新打开，所有数据保留
- [ ] 网络异常时有友好的错误提示
- [ ] 空状态页面（无 Provider、无 Agent、无对话）有适当提示

## 性能与质量
- [ ] 应用冷启动时间 < 2s
- [ ] 聊天滚动流畅，无明显卡顿
- [ ] 流式输出首字节延迟 < 500ms（网络良好时）
- [ ] 无明显内存泄漏
- [ ] 数据库查询响应快速（< 100ms）
